# 日文溝通練習

給自己用的日文（＋英文）練習網站，手機優先。以 JLPT N5 單字為主，每個字附三句**實際溝通會用到的例句**（中／英／日），情境是：

- ✈️ 旅遊：問路、點餐、飯店、交通
- 🎮 遊戲開發：跟日本合作方開會、回報 bug、確認時程
- 📣 遊戲行銷：跟玩家互動、社群貼文、媒體與實況主合作

網址：**https://wiliekimo.github.io/nihongo-app/**

## 功能

- **今日練習**：間隔重複排程，答對的字隔越久才再出現，答錯的很快會再考
- **六種題型**：意思（日→中）、單字（中→日）、聽力、例句填空、怎麼說（情境選句）、英文填空
- **情境小考**：選旅遊／開發／行銷，專練例句題
- **語氣標示**：禮貌體、口語、商務，學會對不同對象怎麼說
- **離線可用**：加到主畫面後，沒網路也能練，紀錄有網路時自動上傳
- **雲端紀錄**：作答紀錄存到你自己的 Google 試算表，Claude 可以讀取並幫你分析

## 加到手機主畫面

- **iPhone（Safari）**：打開網址 → 分享按鈕 → 「加入主畫面」
- **Android（Chrome）**：打開網址 → 右上選單 → 「加到主畫面」／「安裝應用程式」

## 設定雲端紀錄（只要做一次，建議用電腦）

1. 打開 Google 雲端硬碟裡的試算表 **「日文學習紀錄」**
2. 上方選單 **擴充功能 → Apps Script**
3. 把編輯器裡原本的內容全部刪掉，貼上 [`apps-script/Code.gs`](apps-script/Code.gs) 的內容
4. 把第一行附近的 `const TOKEN = 'change-me';` 改成你自己想的密碼（英數字即可），按儲存
5. 上方函式選單選 **`setup`** → 按「執行」→ 依指示授權（會出現「Google 尚未驗證這個應用程式」，點「進階」→「前往…（不安全）」，這是你自己的程式所以沒關係）
6. 右上角 **部署 → 新增部署作業**
   - 類型：**網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」，複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`）
7. 手機打開 App → **設定** → 貼上網址、輸入密碼 → **儲存並測試**

之後如果修改了 `Code.gs`，要到「部署 → 管理部署作業 → 編輯 → 版本選『新版本』」再部署一次，網址不會變。

> 密碼只存在你的 Apps Script 和手機裡，不會上傳到 GitHub。請不要把改好密碼的 `Code.gs` 放回這個公開 repo。

## 專案結構

```
index.html              App 外殼
css/style.css           樣式（含深色模式）
js/                     程式（原生 ES modules，不需要建置）
  app.js                畫面與流程
  quiz.js               出題
  srs.js                間隔重複排程
  state.js / sync.js    本機進度與雲端同步
data/
  decks.json            題庫清單
  n5.json               N5 題庫
  teacher.json          老師設定：給你的話、加強的情境與題型、每日新字數
apps-script/Code.gs     Google 試算表後端
scripts/validate.mjs    題庫格式檢查
sw.js                   離線快取
```

## 本機開發

```bash
python3 -m http.server 8000
```

